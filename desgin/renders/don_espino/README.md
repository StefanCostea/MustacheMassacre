# Don Espino — detail model and combat renders

The original FBX and game motivation document were used as the character and gameplay references. The tall cactus silhouette, thin limbs, oversized split-crown sheriff hat, brown moustache, shorts, boots and belt accessories are retained.

## Current editable model: hero-detail v3

[Open the v3 Blender model](../../character_models/DON_ESPINO_hero_v3.blend) · [View actual renders and reference comparison](v3/README.md)

V3 develops the hero concept into editable three-dimensional detail, including sculpted hair grooves, felt fibers, tailored clothing, detailed boots, an engraved revolver, posed hands and an articulated presentation rig. The [v3 gallery](v3/README.md) also includes actual Blender combat renders and editable scenes for Ricochet Rodeo and High Noon during Stache Frenzy. The sections below retain the earlier v2 work and the original image-generated combat concepts for comparison.

![Actual Blender hero model](v3/01_actual_blender_hero.png)

## Earlier editable model: v2

[Open DON_ESPINO_detail_v2.blend](../../character_models/DON_ESPINO_detail_v2.blend)

The model includes corrected mirrored facial pieces, 171 cactus spines in 57 surface-aligned clusters, areoles, material-specific microtexture, hat and belt stitching, boot decoration and brass rivets. The additions are in a separate named collection. The original FBX is unchanged.

This is an editable presentation model. The inherited animation binding has not been rebuilt or validated for gameplay, and procedural materials have not been baked for engine export. The revolver remains a separate prop, hidden in character inspection renders.

## Combat concepts

A fan-the-hammer shot bounces through three enemies. The clear connected golden path communicates the upgrade.

A critical-hit enemy bursts into cactus needles, carrying the chain reaction to nearby enemies.

With Blender 4.5 installed, run from the repository root:

```sh
blender -b -t 8 --python desgin/tools/inspect_don_espino.py
blender -b -t 8 --python desgin/tools/detail_don_espino.py
```

The scripts recreate the direct Blender renders and presentation model. The combat artwork requires the image generation prompt set and the reference images; it is not generated by Blender.
