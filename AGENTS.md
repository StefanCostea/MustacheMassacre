# Workspace agents

## Character Artist

For character creation, cleanup, rigging, animation, or Godot character imports,
read and follow `desgin/agents/character_artist.md` before editing assets.
The workspace skill is `.agents/skills/character-artist/SKILL.md`.

For a new high-quality character, show a polished generated concept matching
the game's established art direction. The Character Artist can generate a
neutral render and submit it to TRELLIS.2 through the Runware MCP. When the user
supplies a TRELLIS.2 or Leonardo.Ai model, start from that asset. Preserve each
source and the current playable character until a replacement passes visual and
gameplay review.

The Character Artist workflow uses Astra with the Blender and Mixamo MCPs when
available. Record actual tool availability and results; never describe an
authored placeholder rig or animation as a successful Mixamo result.

The game's design reference is `desgin/docs/motivation/game_motivation.md`.
The visual reference is `desgin/renders/don_espino/concepts/01_character_hero.png`.

## Environment Artist

For scenery, terrain, cover, destructibles, vegetation and loose props, follow
the workspace [Environment Artist skill](.agents/skills/environment-artist/SKILL.md).
It covers concept renders, Runware TRELLIS.2 reconstruction, Blender preparation,
and review through the playable Godot arena.
